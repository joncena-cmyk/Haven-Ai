# HAVEN — AI Vehicle Diagnostic System
**Group 3 · CINS Capstone Project**

HAVEN is an AI-powered vehicular diagnostic system analyzing acoustic engine audio and ESP32 accelerometer vibration telemetry.

- **Current Progress**: Stages 1 through 8 completed (Auth, Dashboard, Vehicle Management with NHTSA VIN decoding, 4-Step Capture Wizard with Web Audio oscilloscopes, FastAPI ML Integration with fallback, Printable Inspection Reports, Learning Modules Knowledge Hub, Interactive Siri/Gigi-style AI Mechanic Copilot with voice recognition & speech synthesis, and Async Queue Workers with direct ESP32 Wi-Fi REST IoT Telemetry Ingestion).
- **Modern UI & Responsiveness**: Full SaaS V2.5 layout with sticky topbar navigation, slide-down mobile navigation drawer with backdrop, dual Light / Dark mode themes, and complete mobile phone & tablet responsiveness.

- **ML Backend**: Located in [`ml_backend/`](file:///c:/xampp/htdocs/Haven-Ai/ml_backend) (FastAPI + Librosa)
